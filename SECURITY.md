# Security Policy

## Supported Scope

This repository documents a security assessment of a personal portfolio application. It is not a production software package offered for third-party deployment.

## Reporting a Security Issue

If you identify a security issue in the live portfolio or related services, please report it privately rather than opening a public GitHub issue containing exploit details.

Contact: `delagogah@gmail.com`

Please include:

- affected URL/component
- clear reproduction steps
- expected vs observed behavior
- impact assessment
- screenshots or logs where useful

Do not perform destructive testing, denial-of-service, credential attacks, or access data that is not yours.

## Responsible Disclosure

Reasonable, good-faith reports are welcome. Please allow time for validation and remediation before public disclosure.
